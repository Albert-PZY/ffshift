## Why

这是"视频格式转换器"，却只能同格式重新编码：输出扩展名跟着输入走，用户选不了目标格式。更糟的是 WebM 输入会直接失败——参数固定用 H.264 + AAC，而 WebM 容器只收 VP8/VP9/AV1 与 Vorbis/Opus。README 却写着支持 webm，属于虚假承诺。

## What Changes

- 增加输出格式选择：MP4 / MKV / MOV / WebM / 保持原格式；选择会被记住
- 参数构造按目标容器选编码器：WebM 用 VP9 + Opus 且强制软编，其余用 H.264 / H.265 + AAC
- 输出扩展名优先于格式参数：ffmpeg 按文件名选封装器，参数必须跟它一致
- 连带的两个修复：转换失败时也清理半成品（此前只有取消才清）；错误翻译覆盖"容器不收这个编码"

## 影响

- 不改 ffmpeg 调用方式，只改参数与路径生成
- 旧设置的输出格式缺省为"保持原格式"，行为与升级前一致
