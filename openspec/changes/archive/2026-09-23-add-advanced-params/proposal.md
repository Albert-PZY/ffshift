## Why

档位设计照顾了"不想懂参数"的人，但把另一类用户挡在外面：要控制 GOP、要指定 profile 给老设备、要把音频降到单声道 64k 的人。他们的替代方案是打开命令行自己敲 ffmpeg——那这个工具对他就没有价值了。

加参数面板不是把 ffmpeg 的全部选项倒出来，而是**挑出真正会被用到的 20 项**，配上范围校验，让填错的人在点转换之前就知道错了。

## What Changes

- 参数模型 20 项：编码器、CRF / 目标码率、编码速度、tune、profile、像素格式、关键帧间隔、缩放、缩放算法、帧率、音频模式 / 编码器 / 码率 / 采样率 / 声道、faststart、线程数、额外参数
- 校验按真实约束：CRF 区间随编码器变、容器兼容按系族判、危险开关拦截；错误拦下、警告放行
- 预设：7 个内置 + 用户自定义（增删、JSON 导入导出、重名加序号）
- 与档位共存：字段为 null 表示不干预，产出与以前逐字节一致

## 影响

- `ConvertOptions` 增加 `advanced`；`buildArgs` 的优先级固定为：专业设置 → 目标体积 → 容器固定编码器 → 档位
- 画面滤镜与 alpha 合成共存：有滤镜时并进 `filter_complex`，不用 `-vf` 覆盖
- `AppSettings` 升到 v3：增加 `presets`
- 新增两个 IPC：`read-presets` / `write-presets`
- 顺手修：`.menu` 样式缺失导致下拉是浏览器默认浅色框
