## Why

需求方要求设置页支持调全局字体大小。

这个项目的尺寸是从一个根字号派生的：`html { font-size: var(--font-size-base) }`，全站的文字、间距、控件高度、圆角都写成 rem。所以"调字号"在这里天然是**整体缩放**——这正是想要的效果，但也带来两个必须一起处理的问题：

1. 有几处小字当时写的是固定像素（`text-[10px]` / `text-[11px]`）。它们不跟着放大，就会出现"正文大了、标签还是原来那么小"——而需要放大字号的用户，往往正是看不清这些小字的人。
2. 三栏里有两栏是固定宽度面板。940×600 在 14px 下是宽松的，16px 下实测会挤成一团（中心栏只剩 290px，队列头部按钮重叠、底栏换行）。

## What Changes

- 设置页「外观」分类加字号档位：小 13px / 标准 14px / 大 15px / 更大 16px，默认标准
- 两档小字号改成 rem 令牌（`text-label` ≈ 10px、`text-metric` ≈ 11px），跟着根字号一起放大
- 两栏面板宽度与缩略图改成 rem，随字号等比缩放；标题栏高度与窗口按钮仍是固定像素——它们要和系统一致
- **窗口最小尺寸随字号等比放大**（940×600 × 当前档位/14）。字号变大而当前窗口小于新下限时，窗口会被主动撑开
- 字号与主题一样走"建窗口之前读出来 → 塞进 argv → 首帧前应用"，启动不会先小后大地跳一下
- 设置文件加 `fontSize` 字段（版本 5 → 6），存的是档位名而不是像素值

## 影响

- 旧设置文件缺该字段时回落成"标准"，行为与升级前一致
- 窗口在选到更小档位时不会自动缩回去（只放宽下限），避免打断用户
- 不影响：三档质量、输出格式、目标体积、专业参数、主题
