# FFShift 界面规格（交给 v0.app 重构用）

> 把这份文件整段喂给 v0.app 即可。它是自包含的：不依赖任何代码上下文。
> 重构目标：保持功能与交互不变，重做视觉与布局。
> 技术栈：桌面应用（Electron），界面是 React + TypeScript；重构时可以用 Tailwind + shadcn/ui。
> 界面语言：**中文**，不要出现英文标签。

## 1. 这个产品是什么

一句话：Windows 桌面视频格式转换器。用户把视频拖进来，选一个质量档位和一个输出格式，点开始，看着进度，完成后打开输出目录。

它代替的是"打开命令行敲 ffmpeg 参数"这件事——所以界面的首要目标是**让人不用理解参数也能做出正确选择**。

## 2. 界面结构（单屏，五个区域，从上到下）

```
┌──────────────────────────────────────────────────┐
│ ① 顶栏    品牌 ＋ 运行状态（只读）                  │
├──────────────────────────────────────────────────┤
│ ② 工具栏  档位三选一 ＋ 输出格式 ＋ 文件操作        │
├──────────────────────────────────────────────────┤
│ ③ AI 建议 一句话输入 ＋ 建议结果                    │
├──────────────────────────────────────────────────┤
│ ④ 任务列表（占满剩余高度，可滚动；空时显示引导）     │
├──────────────────────────────────────────────────┤
│ ⑤ 底栏    统计 ＋ 开始转换（唯一主按钮）            │
└──────────────────────────────────────────────────┘
   整窗都是拖放投放区（拖动文件进入时整窗出现虚线描边）
```

## 3. 逐区域功能

### ① 顶栏

| 位置 | 内容 | 说明 |
| --- | --- | --- |
| 左 | **FFShift** ＋ 标语「ffmpeg 的换挡键」 | 品牌名粗体，标语用小号次要色 |
| 右 | 硬件加速状态 | 有可用编码器时：`硬件加速可用：nvenc / qsv / amf`；否则：`使用 CPU 编码` |
| 右 | ffmpeg 版本 | 取版本字符串前三个词，如 `ffmpeg version 9.0.2-essentials_build-www.gyan.dev`；悬停显示完整；检测不到时：`未检测到 ffmpeg` |

### ② 工具栏

**档位选择**（三选一，单选语义）：

| 内部值 | 显示名 | 悬停提示 | 说明 |
| --- | --- | --- | --- |
| `clear` | 更清晰 | 存档、还要再剪辑 | |
| `balanced` | 均衡 | 日常使用 | **默认选中** |
| `small` | 更小 | 发手机、省空间 | |

选中态用强调色描边；未选中为中性描边。

**输出格式**（下拉，按组分）：

- 视频：`保持原格式`（默认）、`MP4（最通用）`、`MKV（装得下几乎一切）`、`MOV（苹果生态）`、`WebM（网页、体积小）`
- 动图：`GIF（自动调色板）`
- 音频（只留声音）：`MP3`、`M4A`、`Opus`、`FLAC（无损）`、`WAV（无损）`

**目标体积提示**（条件显示）：仅当 AI 建议带出体积时出现，文案 `目标体积 50 MiB`。

**右侧按钮**：

- `清空已完成`：幽灵按钮，移除全部已完成任务
- `选择文件`：描边按钮，打开系统文件选择框（支持多选）

### ③ AI 建议区

- 输入框，占位符：`一句话说用途，比如：压到 50MB 发微信`
- 按钮 `让 AI 给建议`：输入为空时禁用；请求中显示 `正在想…`
- 回车等同点击按钮
- 有结果时下方展开一条建议：

```
[模型建议]  建议用「更小」档，目标体积 50 MiB，要发给手机或微信（模型没按格式答，已从回答里提取要点）   [用这个档]
```

- 来源标签两种：`模型建议`（强调色描边）/ `本地规则`（中性灰）
  —— **降级发生时必须如实标出来源**，这是产品承诺，不是装饰
- `用这个档`：采纳建议，同时设置档位与目标体积

### ④ 任务列表

**每行结构**（行高 64px）：

| 位置 | 内容 |
| --- | --- |
| 左 | 缩略图 96×54，圆角；读取中显示 `…`，取不到图显示 `无图` |
| 中 | 文件名（单行截断，悬停显示完整路径） |
| 中 | 媒体信息：`时长 · 宽×高 · 体积`，例：`0:05 · 1280×720 · 4.5 MiB` |
| 中 | 转换中额外一行：进度条 ＋ `百分比 · 剩余 X · 速度`，例：`42.1% · 剩余 约 12 秒 · 1.5x` |
| 右 | 状态文字 ＋ 该状态可用的动作 |

**媒体信息的降级规则**（务必保留）：

- 时长读不出来 → 显示 `时长未知`（不要显示 0:00）
- 信息还没读到时 → 显示读取失败原因，或 `正在读取…`
- 进度条：百分比算不出来时（时长未知）走**不确定态**（来回滑动），文字显示 `进行中`，不要假装有个具体百分比

**状态与可用动作**：

| 状态值 | 文案 | 颜色语义 | 可用动作 |
| --- | --- | --- | --- |
| `reading` | 读取中 | 次要 | — |
| `ready` | 待转换 | 次要 | — |
| `queued` | 排队中 | 强调 | — |
| `running` | 转换中 | 强调 | `取消` |
| `done` | 已完成 | 成功 | `打开输出目录`、`移除` |
| `failed` | 失败 | 危险 | `移除` |
| `cancelled` | 已取消 | 警告 | `移除` |
| `unsupported` | 不支持 | 危险 | `移除` |

**空态**（列表为空时居中显示）：

```
把视频拖进来，或者点上面的「选择文件」。
支持 mp4、mov、mkv、avi、webm 等常见格式。
```

### ⑤ 底栏

- 左：统计文字
  - 没有文件：`还没有文件`
  - 有文件：`共 7 个 · 待转换 3 个`，有进行中时追加 ` · 正在进行 1 个`
- 右：**主按钮**（每屏只有一个，反白：浅底深字）
  - 有待转换任务：`开始转换`
  - 有任务进行中：`继续排队`
  - 没有可转换任务：禁用

## 4. 关键交互（重构时不能丢）

1. **拖放**：整窗可投放；拖动中整窗显示虚线描边；支持一次拖入多个
2. **队列串行**：一次只转换一个任务，完成一个自动开始下一个
3. **读取流程**：加入列表 → `读取中` → 探测媒体信息 → 生成缩略图 → `待转换`；失败则 `不支持` 并显示原因
4. **重复导入**：同一路径已在列表里就忽略，不重复添加
5. **取消**：立即停止并清理未完成的输出文件，任务标记 `已取消`（不是失败）
6. **设置记忆**：档位、输出格式会保存，下次启动恢复
7. **不覆盖源文件**：输出路径是"原名 + `.ffshift` 后缀"

## 5. 渲染需要的数据字段

界面用到的字段（重构时按这些建模 props）：

```ts
// 一个任务
interface TaskItem {
  id: string;
  path: string;              // 完整路径，悬停显示
  name: string;              // 文件名
  sizeBytes: number;
  thumbnail: string | null;  // dataURL（base64 图片）
  status: 'reading' | 'ready' | 'queued' | 'running' | 'done' | 'failed' | 'cancelled' | 'unsupported';
  info: {
    durationSec: number | null;   // null = 未知
    width: number | null;
    height: number | null;
    fps: number | null;
    videoCodec: string | null;
    audioCodec: string | null;
    channels: number | null;
    container: string | null;
    bitrateKbps: number | null;
    hasAudio: boolean;
    pixelFormat: string | null;
    hasAlpha: boolean;
  } | null;
  progress: {
    percent: number | null;       // 0–1，null = 算不出来
    remainingSec: number | null;
    outTimeSec: number | null;
    speed: number | null;         // 倍数，如 1.5
    totalSizeBytes: number | null;
  } | null;
  output: string | null;      // 完成后的产物路径
  reason: string | null;      // 不支持 / 失败的原因（人话）
}

// AI 建议
interface Suggestion {
  preset: 'clear' | 'balanced' | 'small';
  targetSizeMiB: number | null;
  reason: string;
  source: 'ai' | 'rules';     // 必须展示给用户
}
```

**格式化规则**（数字不要按原值直接显示）：

| 字段 | 规则 | 例 |
| --- | --- | --- |
| 体积 | 二进制单位，保留一位小数 | `4.5 MiB` / `512 B` |
| 时长 | 不足一小时 `分:秒`，超过 `时:分:秒` | `0:05` / `1:02:05` |
| 百分比 | 保留一位小数 | `42.1%` |
| 速度 | 倍数，最多两位小数、去掉多余的零 | `1.5x` / `0.85x` |
| 剩余时间 | 中文，粗略即可 | `约 12 秒` / `约 10 分` / `约 1 小时 5 分` |
| 任何字段缺失 | 显示 `—`，**不要显示 NaN 或 undefined** | |

## 6. 视觉约束

沿用现有设计系统（`docs/design-system.md`）：

- **近中性暗色**：窗口底 `#0B0C0E`，面板 `#14161A`，悬停 `#1A1D22`
- **单一强调色**：蓝 `#3B82F6`；绿色只用于"已完成"，红色只用于失败，橙色只用于"已取消"
- **主按钮反白**：浅底 `#F5F6F7` ＋ 深色字，**每屏只有一个**
- **层级靠间距、字重、1px 边框**，不靠色块堆叠
- 行高节奏 8px（4 / 8 / 12 / 16 / 24 / 32）；控件圆角 8px，面板 12px
- 数字用等宽数位（`tabular-nums`），让进度与体积对齐
- 正文对比度 ≥ 4.5:1，焦点可见，状态不能只靠颜色表达
- 动效 120–180ms、只做状态反馈；尊重 `prefers-reduced-motion`
- **明确不要**：渐变、发光/霓虹、第二个强调色、装饰插画、滚动特效、emoji 当图标

## 7. 还没做、请勿实现的功能

这些在计划里但代码里没有，重构时**不要**自行加上（加了反而和实际能力对不上）：

- 选择输出目录（当前只能用"与源文件同目录"）
- 文件夹导入（只能选文件或拖文件）
- 托盘通知、系统托盘进度
- 原始日志展开（错误原因有，但原始输出还没做展示入口）
- 直接输入目标体积（目前只能从 AI 建议带入）
- 转换历史记录
- 右键菜单集成
